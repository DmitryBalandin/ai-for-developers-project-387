# Frontend Requirements

Пользователь видит свободные слоты по 30 минут, может выбрать время и оформить запись, а владелец календаря — посмотреть список предстоящих встреч. Этого достаточно, чтобы пройти весь путь от проектирования до запуска сервиса в облаке.

## Детали реализации

- **Гость**: выбирает тип события → видит календарь (до 14 дней) → выбирает дату → видит сетку свободных слотов (30 мин, формат HH:mm) → заполняет имя (обяз.) и email → отправляет бронь → получает подтверждение
- **Владелец**: видит список всех предстоящих броней с именем гостя, временем, email и статусом
- **Обработка ошибок**: 409 Conflict — уведомить гостя что слот занят; пустые состояния — показать сообщение; загрузка — показать скелетон/спиннер
